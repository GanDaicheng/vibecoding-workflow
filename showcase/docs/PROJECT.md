# 项目说明：Vibe Coding 工作流网站与作品目录

## 目标

介绍可安装的 Vibe Coding 工作流 Skill，并提供一个长期收集真实成品网站的公开作品目录，让访客能了解工作流并直接打开作品体验。

## 用户

- Skill 使用者：Codex 新手，了解用途、范围、安装和调用方式。
- 维护者：网站作者，通过编辑项目中的静态数据文件添加真实作品。
- 访客：阅读工作流介绍或浏览作者网站成品的人；首版不限定访客身份。

## 首版范围

- 中文首页介绍 Skill 的用途、适用范围、三步工作方式、安装命令和调用示例。
- 独立作品页展示作品标题、类别、介绍、可选封面和成品链接。
- 按作品类别筛选，保留清晰的空列表状态。
- 首页和作品页在手机上可读、键盘可操作，并尊重减少动态效果偏好。
- GitHub Actions 对 PR 执行轻量检查，`main` 检查通过后发布 GitHub Pages。
- 本地静态数据，无账号、后台、上传、数据库或跨设备同步。

## 数据字段

作品对象需要 `title`、`category`、`description`、`url`；可选 `cover`（项目根目录下图片路径）和 `year`。数据位于 `src/projects.js`，首发为空。新增步骤见本目录 `README.md`。

## 技术选择

首版使用原生 HTML、CSS 和 JavaScript。无需依赖安装或构建；本地直接打开 `index.html` 或通过静态服务器预览。GitHub Actions 将 `showcase/` 作为 Pages artifact。之后若要从网页新增作品或跨设备同步，再讨论后台、数据存储和访问权限。

## 视觉方向

明亮的“网站样本册”视觉：雾蓝灰背景、海军蓝文字、钴蓝交互色和少量青柠强调，用叠放的浏览器窗口作为统一识别图形。使用系统字体，不加载远程字体。
