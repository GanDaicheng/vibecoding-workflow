# 项目说明：网站样本册

## 目标

为网站作者提供一个长期收集成品网站的作品集目录，让访客能了解每个网站并直接打开体验。

## 用户

- 维护者：网站作者，通过编辑项目中的静态数据文件添加作品。
- 访客：浏览作者网站成品的人；首版不限定访客身份。

## 首版范围

- 单页展示作品标题、类别、介绍、可选封面和成品链接。
- 按作品类别筛选，保留清晰的空列表状态。
- 手机可读、键盘可操作，并尊重减少动态效果偏好。
- 本地静态数据，无账号、后台、上传、数据库或跨设备同步。

## 数据字段

作品对象需要 `title`、`category`、`description`、`url`；可选 `cover`（项目根目录下图片路径）和 `year`。数据位于 `src/projects.js`，新增步骤见根目录 `README.md`。

## 技术选择

首版使用原生 HTML、CSS 和 JavaScript。无需依赖安装或构建；本地直接打开 `index.html`。这种方式易维护，也能作为静态网站部署。之后若要从网页新增作品或跨设备同步，再讨论后台、数据存储和访问权限。

## 视觉方向

明亮的“网站样本册”视觉：雾蓝灰背景、海军蓝文字、钴蓝交互色和少量青柠强调，用叠放的浏览器窗口作为统一识别图形。使用系统字体，不加载远程字体。
