A CLEAR WAY TO BUILD

先理清路线，
再把每一步走完.

Skill 会把大任务拆成看得见、能检查的小步。重要决定由你确认，普通实现细节由 Codex 处理。

01 / CLARIFY

先说清要做什么

区分小改动、新项目和多步骤功能，确认目标用户、交付终点和首版范围。

?
02 / PLAN

再决定怎么实现

按需求选技术，判断是否需要数据库，并把核心故事对应到页面、开发切片和验收方式。

03 / BUILD

完成后实际检查

MADE FOR A PRACTICAL FIRST VERSION

适合从小型网站开始，
不把复杂需求藏起来。

首版重点是公开展示页面。登录、管理后台、上传、支付或敏感数据会增加权限和数据设计；遇到这些需求，工作流会先停下来重新确认范围。
